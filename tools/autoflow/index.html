Installation Steps

Install in under a minute via Chrome's developer mode.

  1. Download the Auto Flow ZIP archive above.
  2. Extract the ZIP contents to a folder on your system.
  3. Navigate to chrome://extensions in Chrome.
  4. Toggle Developer mode in the top right.
  5. Click Load unpacked and select the unzipped folder.
  6. Open Google Flow and launch Auto Flow from your toolbar.
